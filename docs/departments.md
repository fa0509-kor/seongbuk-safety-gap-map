## 옹벽·축대는 조직도에 담당이 적혀 있지 않음
- 도로 쪽 사면은 도로과 도로시설팀, 급경사지 지정 대상은 도시안전과 안전지원팀, 민간 안전취약시설은 건축과 건축안전팀으로 나뉠 것으로 보이지만 홈페이지 업무 문구로는 확인되지 않음
- 서비스 처리: 옹벽·축대 제보는 **도시안전과 안전지원팀에 1차 배정**하고 담당자가 재배정 (관리자 상세의 '담당 부서' 수정)
- 발표에서 쓸 때: "옹벽·축대 담당이 조직도에 따로 적혀 있지 않다"까지만. "담당이 없다"고 단정하지 않음

## 배정 규칙에 필요한 것
- 지금 제보에는 **시설 종류**가 없다 (AI는 결함 유형만 냄: 균열·박리·백태·철근). 부서는 결함이 아니라 시설 종류로 갈림
- 방법 (결정 필요): ① 제보 3단계에 '시설 종류' 선택(옹벽·축대 / 도로·보도 / 계단 / 공원·놀이시설 / 건물 / 하천 / 모름) 추가 → 위 표로 배정, '모름'은 도시안전과 안전지원팀 ② 전부 도시안전과 안전지원팀에 1차 배정 후 사람이 재배정
