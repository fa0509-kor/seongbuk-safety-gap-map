## 연동 설계

1. 시연 (11/6~7): `poc/test_vision.py` 구조. 5유형 + 긴급도 JSON 고정 응답을 화면에 연결
2. 평가: AI-Hub 이미지 클래스별 수십 장을 같은 프롬프트로 분류시켜 정답 라벨과 비교. 클래스별 재현율·정밀도·F1, 혼동행렬. 위험을 놓치는 것이 더 치명적이므로 재현율 우선 (노션 기획안 기준)
3. 분리: 학습 70 / 검증 15 / 테스트 15. 같은 시설물·촬영 단위는 한 세트에만 (노션 기획안 기준)
4. 별도 시험: 성북구 현장 사진 몇 장으로 AI-Hub와의 성능 차이를 따로 측정해 한계로 밝힘 (노션에서 가산점으로 봄)
5. 고도화: AI-Hub 라벨 + 성북구 제보 사진(담당자가 고친 라벨)으로 파인튜닝

## 발표 방어 논리 (3줄)

1. 시연은 Vision API 프롬프트로 위험 유형 5종과 긴급도 3단계를 분류하고, 응답을 JSON으로 고정해 화면에 바로 연결함
2. 정확도는 AI-Hub 균열 데이터로 클래스별 재현율·정밀도를 먼저 측정하고, 성북구 현장 사진으로 따로 시험해 차이를 한계로 밝힘
3. 제보 사진에 담당자가 고친 라벨이 쌓이면 AI-Hub 데이터와 함께 파인튜닝해 오분류와 API 비용을 줄이고, 같은 구조를 다른 구에 이식함

## 질의응답 대비

- "AI-Hub 데이터로 이미 학습했나?" → 학습 결과가 나오기 전에는 "아니오, 현재는 평가 설계 단계"라고 답하고 수치를 쓰지 않음 (노션 기획안: 결과가 없으면 평가 설계만 제시)
- "옹벽 사진 데이터가 있나?" → 있음. AI-Hub 균열 데이터에 옹벽 전용 파일이 있다. 다만 주민 스마트폰 사진과 촬영 조건이 같은지는 미확인이라 성북구 현장 사진으로 따로 검증 예정
- 건수·정확도는 확인한 숫자만 말할 것

## 신청 결과와 샘플 확인 (10/19)

- 신청 목적 "인공지능 경진대회 참가"로 신청, 마이페이지에서 **승인 1건** 확인. 승인 후 3개월간 다운로드 가능(이후 재승인)
- 약관 요지: 학습용으로만 사용, 한국지능정보사회진흥원 사업 결과임을 밝힐 것(2차 저작물 포함), 승인 안 받은 다른 사람에게 열람·제공·양도 금지, 국외 반출 금지
  - **팀원에게 파일을 넘겨주면 안 됨.** 데이터를 쓰는 사람은 각자 신청해야 함
  - PPT·결과물에 출처 표기 필요
- 받은 것: 샘플(경량) 데이터 617MB → `data/raw/aihub/crack_Sample.zip`
  - 이미지 2,057장 + 라벨 JSON 2,057개. 모든 이미지가 균열 포함(Y)
  - 시설물: 도로교량 725, 철도교량 663, 수로터널 386, 댐 164, **옹벽 104**, 지하차도 11, 도로터널 4
  - 라벨 이름(영문): reticular crack 3,022 / crack 1,293 / leak 556 / efflorescence 482 / damage 405 / rebar 351 / material separation 295 / detachment 269 / spalling 222 / exhilaration 145
  - 라벨은 이미지 분류용이 아니라 선(Polyline)·면(Polygon) 위치 표시. 이미지 한 장에 여러 라벨이 있을 수 있어, 분류용으로 쓰려면 이미지당 대표 라벨을 정하는 규칙이 필요
  - 이미지 크기 1920x1080, 촬영 장비는 샘플 첫 파일 기준 스캐닝
- 옹벽 전체(TS 9.16GB, VS 1.14GB)는 아직 안 받음. C 드라이브 여유가 28GB라 TS는 보류. VS 1.14GB는 받을 수 있음
- 큰 파일은 분할 압축이라 윈도우에서 합치려면 WSL 필요
