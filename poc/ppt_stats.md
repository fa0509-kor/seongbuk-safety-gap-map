## 14장. 기대효과 추정 (가정값 기준)

### A. 점검 범위 압축

| 항목 | 값 | 계산 |
| --- | ---: | --- |
| 전수 점검 대상 | 326개소 | 해빙기 점검 관리대상 (팀 자료) |
| 우선 파견 대상 | 65개소 | 326 x 20% = 65.2, 반올림 |
| 생략되는 현장 방문 | 261개소 | 326 - 65 |
| 방문 절감 비율 | 80.1% | 261 / 326 |

- 시간·비용 절감 비율은 **현장 1곳당 시간과 비용이 같다는 가정**에서 방문 횟수 절감 비율과 동일 (80%)
- 1곳당 이동·점검 시간, 인건비는 구청 자료가 없어 절대 금액·시간으로는 환산하지 않음
- 상위 20%는 기획안 가정. 상위 20%에 실제 위험 지점이 얼마나 들어가는지(재현율)는 검증 전
- 나머지 261개소도 제외가 아니라 후순위 정기 점검 대상

### B. 보고서 작성 시간 단축

| 항목 | 기존 수기 | LLM 자동 생성 |
| --- | ---: | ---: |
| 건당 시간 | 30분 | 10초 |
| 326개소 전체 | 163시간 | 54.3분 |
| 우선 65개소만 | 32.5시간 | 10.8분 |
| 단축률 (전체 기준) | | 99.4% |

- 건당 30분은 기획안 가정값, 10초는 목표치. 시연에서 실측해 교체
- LLM은 고정 템플릿에 DB 집계값을 채우는 용도. 점검 담당자의 현장 확인·검토 시간은 포함하지 않음
- 합산 효과: 방문 80% 절감 + 보고서 시간 99% 단축은 서로 다른 항목이므로 곱하거나 더해서 하나의 숫자로 쓰지 않음
